# Agile Planning

This repository contains the work completed for the Agile Planning hands-on lab.

## Project Overview

The purpose of this project is to practice Agile planning concepts, including:

- Creating a Product Backlog
- Creating user stories
- Using issue templates
- Estimating story points
- Identifying technical debt
- Planning a sprint
- Organizing work using Agile practices

## User Story Template

The user story template is available in:

`user-story.md`

## Sprint

The hands-on lab focuses on creating **Sprint 0** as preparation for the first development sprint.
